# P1 · 需求基线

> 输入：《统一门户系统需求规格说明书（原型设计版）V0.9》  
> 项目：卫健XC统一门户系统  
> 阶段：P1  
> 版本：0.1.0  
> 当前基线：V20260917-01

## 1. P1 阶段目标

按照新建项目 SOP，P1 只完成：角色/参与方、核心业务对象、项目范围、核心功能。

不跨入 P2 页面规格/流程/状态机定稿，也不跨入 P3 数据库设计。

## 2. 需求可信度标记

### A · 已确认基线
- 门户不拥有用户管理权。
- 门户角色仅管理门户自身权限。
- 子系统负责访问授权、开户、业务角色和业务权限。
- 约43个系统全部进入“全部应用”。
- 上层无用户时跳转上层平台注册/开通。
- 约43个系统待办全部接入。
- 约43个系统消息全部接入。
- 通知公告仅门户自身发布。
- 门户统一提供短信服务。
- 数据汇聚治理不属于门户后台。
- “我的应用 + 全部应用”采用混合模式。
- 支持统一身份与子系统账号映射。
- 支持用户自助关联已有子系统账号。

### B · 需求文档中的建议项
以下只保留为后续设计输入，不在 P1 直接冻结：
- 超级管理员/应用管理员/集成管理员/公告管理员/短信管理员/审计管理员等具体角色拆分。
- 页面建议字段。
- 状态枚举建议。
- SSO协议候选类型。
- 自动关联/审核关联/管理员关联等映射模式的完整启用范围。
- 首页和管理端具体指标布局。
- 原型页面批次和具体视觉布局。

### C · 待确认
- 上层认证协议、手机号认证能力、唯一用户ID。
- 43个子系统 SSO / 待办 / 消息接口实际能力。
- 消息已读回传。
- 自助关联验证接口。
- 高权限账号审核规则。
- 短信厂商/协议/模板审批。
- Session 与安全策略。
- 公告附件、收藏应用、待办留存、日志留存等在 P1 形成时待确认；已由 P2 ADR-011～ADR-013 解决：支持附件、不提供收藏、留存配置化。仅最终留存天数待实施确认。

## 3. P1 角色模型

| 类型 | 角色/参与方 | P1定位 |
|---|---|---|
| 用户 | 公众侧用户 | 使用公众侧权威身份认证进入门户 |
| 用户 | 政务侧用户 | 使用政务侧权威身份认证进入门户 |
| 用户 | 门户普通用户 | 使用应用、待办、消息、公告、个人中心 |
| 管理 | 门户管理员 | 管理门户自身能力，不接管子系统权限 |
| 候选管理角色 | 超级/应用/集成/公告/短信/审计管理员 | 需求文档建议，后续权限矩阵阶段冻结 |
| 外部系统 | 公众侧身份平台 | 身份权威来源、注册/认证 |
| 外部系统 | 政务侧身份平台 | 身份权威来源、开通/认证 |
| 外部系统 | 约43个业务子系统 | 业务账号、角色、权限、待办、消息、SSO |
| 外部服务 | 短信服务商 | 短信发送通道 |

## 4. P1 核心业务对象

| 业务域 | 核心对象 |
|---|---|
| 身份 | 身份源、统一身份索引、上层身份映射、Session |
| 应用 | 门户应用/业务子系统、系统分类 |
| 账号映射 | 子系统账号映射、映射异常 |
| 门户权限 | 门户角色、门户权限 |
| 待办 | 聚合待办 |
| 消息 | 聚合消息、门户自身消息 |
| 公告 | 门户通知公告 |
| 集成 | SSO接入、待办接入、消息接入配置 |
| 短信 | 短信渠道、模板、接入应用、发送记录 |
| 配置 | 系统配置 |
| 监控 | 接口/服务运行状态 |
| 审计 | 登录、认证、访问、门户操作、接口、异常日志 |

| 一级能力 | 核心功能 | 状态 |
|---|---|---|

| 消息 | 43系统消息汇聚 + 门户自身消息 | 范围内 |
| 公告 | 门户公告发布与用户查看 | 范围内 |
| 门户权限 | 门户角色和门户自身权限 | 范围内 |
| 应用接入 | 应用登记、分类、接入配置 | 范围内 |
| 业务集成 | SSO、待办、消息接入配置 | 范围内 |
| 短信 | 统一短信渠道/模板/应用/发送/重试/统计 | 范围内 |
| 运行监控 | 身份平台、SSO、待办、消息、短信监控 | 范围内 |

| 子系统权限 | 子系统角色/菜单/数据权限 | 不在范围 |
| 子系统业务流程 | 子系统业务审批和开户审批 | 不在范围 |

## 6. 影响分析

| 资产 | 本次影响 | P1处理 |
|---|---|---|
| 页面 | 有，确定三个使用区域及功能域 | 仅范围级，不生成页面规格 |
| 数据库 | 无直接变更 | 不生成 Schema/Migration/Seed |
| 状态机 | 潜在影响 | 需求中的状态仅作为 P2/P3 输入，不冻结 |
| 操作矩阵 | 有前置影响 | 确认门户权限边界，不生成按钮矩阵 |
| 权限 | 有 | 确认门户权限与子系统权限分离 |
| 消息 | 有 | 从 reserved 升级为正式范围能力 |
| 操作履历/审计 | 有 | 日志审计进入范围，不设计字段/落库 |
| 统计口径 | 有前置影响 | 管理首页、短信统计进入范围，不冻结公式 |
| 交付文档 | 有 | 更新项目档案、范围、ADR、P1基线、CHANGELOG |
