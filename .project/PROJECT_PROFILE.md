- 项目类型：new
- 当前阶段：P4核心Mock已运行；0.3.0-A前端Mock改造进行中
- 当前代码版本：0.2.0

- 数据环境：PostgreSQL 14 + NocoDB；P3历史数据库验收事实保留

## 项目定位

系统作为统一门户中间层：

```text
闽政通（公众）
闽政务（政务）
门户本地账号
       ↓
卫健统一门户
       ↓
约43个业务子系统
```

## 身份与用户

- 闽政通 → CITIZEN / 公众用户
- 闽政务 → GOV / 政务用户
- 门户本地 → LOCAL / 门户本地用户

LOCAL是门户自有身份，首期主要用于平台维护人员登录管理端。

门户不修改闽政通/闽政务权威身份资料；LOCAL身份资料和密码由门户负责。

## 角色

默认仅：

- SUPER_ADMIN / 门户超级管理员
- PORTAL_ADMIN / 门户管理员

底层保留MENU/PAGE/ACTION RBAC。

第一阶段不预置多个细分管理员角色，不优先建设复杂数据范围。

## 公共模块

- 用户管理：统一查看CITIZEN/GOV/LOCAL；LOCAL支持新建、启停、角色、重置密码
- 角色管理：两默认角色 + 菜单/页面/操作权限
- 组织管理：门户组织索引；政务用户优先闽政务，LOCAL/CITIZEN可为空
- 字典管理：应用分类、公告类型、组织类型等
- 消息：子系统PUSH + 门户消息
- 日志：登录/认证、访问、操作、API、异常
- 运行监控：SSO/TODO/MESSAGE

## 权限边界

门户不管理：
- 子系统业务角色
- 子系统菜单权限
- 子系统数据权限
- 子系统开户审批

应用入口资格与子系统业务授权分离。
