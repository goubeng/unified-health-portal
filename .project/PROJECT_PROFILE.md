# 项目档案

- 项目名称：卫健XC统一门户系统
- 项目简称：卫健XC统一门户
- 项目类型：new
- 当前阶段：P4 Gate 已通过；P5 本地数据库高保真演示版闭环，进入下一阶段范围定义
- 当前代码版本：0.2.0
- 当前目标设计：V20260921-01
- 技术栈：Vue 3 + Vite + TDesign Vue Next
- Base Project：office-house 0.1.0（仅参考UI/交互规范）
- 数据环境：PostgreSQL 14 + NocoDB；当前本地演示业务使用数据库模式，P3历史数据库验收事实保留

## 项目定位

系统作为统一门户中间层：

```text
闽政通（公众）
闽政务（政务）
门户本地账号
       ↓
卫健统一门户
       ↓
42个业务子系统
```

## 身份与用户

- 闽政通 → CITIZEN / 公众用户
- 闽政务 → GOV / 政务用户
- 门户本地 → LOCAL / 门户本地管理账号

LOCAL是门户自有身份，首期主要用于平台维护人员登录管理端。

门户不修改闽政通/闽政务权威身份资料。当前登录与本地账号密码维护仅作页面交互演示，不进行真实凭证校验，也不要求将密码写入数据库；正式凭证管理属于以后另行确认的生产能力。

## 角色

默认仅：

- SUPER_ADMIN / 门户超级管理员
- PORTAL_ADMIN / 门户管理员

底层保留MENU/PAGE/ACTION RBAC。

第一阶段不预置多个细分管理员角色，不优先建设复杂数据范围。

## 公共模块

- 用户管理：统一查看CITIZEN/GOV/LOCAL；LOCAL支持新建、启停、角色、重置密码
- 角色管理：两默认角色 + 菜单/页面/操作权限
- 组织管理：门户组织索引；政务用户优先闽政务，LOCAL/CITIZEN可为空
- 字典管理：应用分类、公告类型、组织类型等
- 消息：子系统PUSH + 门户消息
- 日志：登录/认证、访问、操作、API、异常
- 运行监控：SSO/TODO/MESSAGE

## 权限边界

门户不管理：
- 子系统业务角色
- 子系统菜单权限
- 子系统数据权限
- 子系统开户审批

应用入口资格与子系统业务授权分离。

## 下一阶段重点

当前可启动演示版后续质量与交付收口；具体任务、验收标准和是否涉及生产级建设须单列确认。以下已不作为本阶段 Gate 阻断：正式认证及密码凭证落库、42 个子系统逐一联调。接口契约和配置页面继续保留，不能将“已预留”记为“已接通”。

## 当前演示版实施边界

- P4 页面与业务链路已验收；P5 的本地数据库演示闭环已达成，公告等核心业务写入可持久化，演示状态与异常场景由本地数据支持；

- SSO/TODO/MESSAGE 及上下游系统保留接口契约、模拟收发与连接配置页面，不宣称真实联调；
- 旧计划中的生产级 B/C 目标并未因此自动完成，下一阶段具体范围待确认。阶段证据与增量复核见 [当前 P4/P5 阶段 Gate 复核](../docs/02-开发/02-评审/当前P4-P5阶段Gate复核.md)。
