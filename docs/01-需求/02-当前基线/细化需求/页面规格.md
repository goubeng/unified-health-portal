# 页面规格（V1.0）

> 基线：V20260920-03。

## PG-001 统一登录

用户端和平台管理端共用同一个 `/login`，不建设两套独立登录页。

登录页提供三个入口/Tab：

### 公众用户

- 身份来源：闽政通；
- 扫码/手机号等具体能力按外部身份源接口；
- 登录成功默认进入用户端。

### 政务用户

- 身份来源：闽政务；
- 扫码/手机号/上层免登等具体能力按外部身份源接口；
- 登录成功默认进入用户端；
- 若拥有有效门户管理角色，可在登录后进入/切换平台管理端。

### 管理账号

使用门户本地账号密码登录。

字段：
- 登录账号
- 密码
- 验证码/滑块（按最终安全方案）
- 登录按钮

规则：
- 用户必须为LOCAL来源；
- 账号必须启用且未锁定；
- 密码校验通过；
- 必须拥有有效管理角色；
- 首次登录可强制改密；
- 登录成功第一阶段默认进入平台管理端。

手机号登录滑块删除下方“按住滑块向右拖动/已通过人机验证”图标与文字。

三类方式认证成功后统一创建 Portal Session，再根据用户类别和门户角色决定可访问端。

## PG-002 认证结果

覆盖：
- 登录成功；
- 认证失败；
- 账号停用；
- 账号锁定；
- 无管理权限；
- 外部认证异常；
- Session建立失败。

## PG-101 用户首页

用户端默认面向CITIZEN/GOV。顺序：待办 → 公告 → 消息 → 我的应用。Loading结束前不得显示Empty。

## PG-102/103 应用中心

根据用户类别、应用适用范围、访问模式和入口资格决定按钮：

- 进入应用；
- 关联账号；
- 继续验证；
- 等待审核；
- 处理关联冲突；
- 申请使用；
- 查看申请。

### BIND关联账号交互

当应用需要BIND且当前用户无有效BOUND映射：

1. 门户先尝试可信唯一标识匹配；
2. 无可信ID时，可用姓名+已登记手机号、姓名+工号等查找候选账号；
3. 候选匹配成功后不得直接绑定，进入二次验证；
4. 验证方式按子系统能力显示：
   - 跳转子系统认证；
   - 向子系统登记手机号发送验证码；
   - 上层身份重新认证；
   - 原系统账号一次性校验；
   - 提交管理员审核；
5. 普通账号验证通过后可BOUND；
6. 高权限账号按配置进入“待审核”；
7. 账号已绑定其他门户用户或匹配多条时显示“关联冲突”，不得自动覆盖。

用户输入子系统密码时页面必须明确“仅用于本次验证、不保存”。

LOCAL首期不默认参与普通应用中心业务。

## PG-205~208 身份与子系统映射

身份来源显示：
- 闽政通
- 闽政务
- 门户本地

### 映射列表建议显示

- 用户
- 用户类别
- 身份来源
- 应用
- 子系统账号
- 子系统用户ID
- 关联方式 AUTO/SELF/REVIEW/ADMIN
- 候选匹配方式
- 验证方式
- 风险级别
- 映射状态
- 子系统账号状态
- 最近验证时间
- 关联时间
- 操作

### 详情/处理能力

- 查看匹配依据和验证方式；
- 查看验证/审核履历；
- 审核高权限账号关联；
- 管理员人工关联；
- 处理 CONFLICT；
- 解绑/重绑；
- 查看关联异常。

规则：

- application_id + external_user_id存在有效BOUND时不得被其他用户直接覆盖；
- 姓名+手机号只作为候选匹配条件；
- 高权限账号可要求REVIEWING；
- 子系统账号DISABLED不等于映射关系被删除，应分别展示账号状态与映射状态。

LOCAL通常无子系统映射；页面允许显示“无映射需求”，不得制造虚假映射。

## PG-209 角色管理

### 默认角色

仅预置：
- 门户超级管理员
- 门户管理员

### 基本信息

- 角色编码
- 角色名称
- 说明
- 启用状态
- 关联用户数

### 权限

菜单 → 页面 → 操作。

第一阶段不强制提供复杂数据范围UI；默认角色使用ALL_PORTAL。

可保留未来“自定义角色”能力，但不预置应用/公告/审计等细分角色。

## PG-220 公告管理

支持草稿、提交、立即/定时发布、预览、Word导入、正文插图、附件、已发布编辑、撤回、撤回/失效删除、永久有效。

## PG-222 运行监控

仅按SSO/TODO/MESSAGE显示真实服务状态。删除额外综合状态。

## PG-228 用户管理

### 查询

- 姓名/账号
- 用户类别
- 身份来源
- 所属组织
- 门户角色
- 启用状态

### 列表

- 序号
- 用户账号
- 姓名
- 用户类别
- 身份来源
- 所属组织
- 门户角色
- 启用状态
- 最近登录
- 操作

### 外部用户操作

允许：
- 查看
- 门户启停
- 分配门户角色（仅授权人员）
- 维护门户组织索引（必要时）

不允许修改：
- 闽政通/闽政务来源
- CITIZEN/GOV
- 权威姓名/手机号/账号

### 本地用户操作

超级管理员可：
- 新建
- 编辑门户资料
- 启停
- 分配角色
- 重置密码
- 解除锁定

密码、密码Hash不得出现在列表/详情/API响应中。

## PG-229 组织管理

政务用户组织优先闽政务；LOCAL组织可选；公众用户不强制组织。

组织首期主要用于资料、公告范围和查询，不作为复杂RBAC数据范围的首期前置条件。

## PG-230 字典管理

承接应用系统分类、公告类型、组织类型等业务字典。

## PG-231 应用访问申请

管理员审核门户入口资格，不审核子系统业务角色。
