# 字段规则（V1.0）

> 基线：V20260920-03。

## 1. 身份来源与用户类别

| identity_source | user_type | 中文 |
|---|---|---|
| MINZHENGTONG | CITIZEN | 闽政通 / 公众用户 |
| MINZHENGWU | GOV | 闽政务 / 政务用户 |
| PORTAL_LOCAL | LOCAL | 门户本地 / 门户本地用户 |

identity_source与user_type是身份属性，不是角色。

## 2. 门户角色

默认：

- SUPER_ADMIN：门户超级管理员
- PORTAL_ADMIN：门户管理员

角色只控制门户权限。

第一阶段默认数据范围：
- SUPER_ADMIN → ALL_PORTAL
- PORTAL_ADMIN → ALL_PORTAL

其它数据范围保留扩展，不作为首期页面必配项。

## 3. 本地用户凭证

本地凭证不得直接与公开用户资料混用明文字段。

建议：

- username
- password_hash
- password_algorithm
- must_change_password
- failed_login_count
- locked_until
- password_updated_at
- last_login_at

禁止：
- password
- plain_password
- 前端返回password_hash

## 4. 用户

统一用户字段：

- unified_user_id
- account
- name
- user_type
- identity_source
- org_id/org_name（可空）
- portal_status
- first_login_at
- last_login_at

LOCAL允许org为空。

## 5. 应用

access_mode：
- DIRECT
- BIND
- REQUEST

account_binding_mode（BIND场景）：
- AUTO
- SELF
- REVIEW
- ADMIN

应用适用用户与门户管理角色分开。

### 5.1 子系统账号映射

建议字段：

- mapping_id
- unified_user_id
- application_id
- external_user_id
- external_account
- binding_method
- binding_status
- match_method
- verification_method
- verification_status
- risk_level
- external_account_status
- verified_at
- reviewed_by
- reviewed_at
- bound_at
- unbound_at
- conflict_reason
- created_at
- updated_at

binding_status建议：
- UNBOUND
- VERIFYING
- REVIEWING
- BOUND
- FAILED
- CONFLICT

external_account_status与映射状态分开：
- ACTIVE
- DISABLED
- UNKNOWN

### 5.2 匹配与验证规则

match_method建议：
- TRUSTED_ID
- NAME_PHONE
- NAME_EMPLOYEE_NO
- ACCOUNT
- MANUAL

verification_method建议：
- SUBSYSTEM_REDIRECT
- SUBSYSTEM_OTP
- UPSTREAM_REAUTH
- SUBSYSTEM_CREDENTIAL
- ADMIN_REVIEW

verification_status建议：
- PENDING
- PASSED
- FAILED
- REVIEW_REQUIRED

risk_level建议：
- NORMAL
- HIGH

姓名 + 手机号仅作为候选匹配，不作为统一主键或直接绑定依据。

SUBSYSTEM_OTP必须发送至子系统已有账号中登记的可信手机号；用户现场新输入的手机号不能单独作为账号所有权证明。

同一application_id + external_user_id最多存在一个有效BOUND映射。

## 6. 应用访问申请

request_no、application_id、user_id、org_id、reason、status、submitted_at、reviewed_by、reviewed_at、review_note、version。

## 7. 公告

- status：DRAFT/SCHEDULED/PUBLISHED/WITHDRAWN/EXPIRED
- publish_mode：IMMEDIATE/SCHEDULED
- scheduled_publish_at
- published_at
- effective_end（NULL=永久有效）
- submitted_at/submitted_by

## 8. 日志

数据库枚举继续使用稳定英文。

登录日志必须保存/输出：
- userType
- identitySource
- loginSource
- loginMethod

LOCAL账号密码登录：
- loginMethod=PASSWORD
- identitySource=PORTAL_LOCAL

## 9. 运行监控

每个SSO/TODO/MESSAGE记录独立status。详情不增加无必要aggregateStatus。
