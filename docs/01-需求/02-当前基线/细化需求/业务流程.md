# 业务流程（V1.0）

> 基线：V20260920-03。

## 1. 总体身份链路

```text
闽政通 → 公众用户 ┐
闽政务 → 政务用户 ├→ 卫健统一门户 → 各业务子系统
门户本地 → 本地用户 ┘
```

## 2. 用户端登录

公众：闽政通认证 → 门户建立/更新统一身份 → CITIZEN → Session → 用户端。

政务：闽政务认证 → 门户建立/更新统一身份 → GOV → Session → 用户端。

## 3. 管理端本地登录

```text
输入门户本地账号/密码
→ 校验账号启用/锁定
→ 校验密码Hash
→ 检查是否拥有管理角色
→ 建立管理端Session
→ 写登录日志
→ 管理端
```

首次登录如设置must_change_password，则先完成改密。

## 4. 外部身份进入管理端

闽政务/闽政通认证 → 统一身份 → 检查门户角色 → 有管理角色则允许进入管理端，否则只进入普通用户端。

## 5. 本地账号创建

超级管理员 → 新建本地用户 → 设置初始账号/临时密码 → 分配门户角色 → 首次登录强制改密。

不开放公众自助注册。

## 6. 角色授权

```text
用户
→ 分配门户超级管理员/门户管理员
→ 菜单/页面/操作权限
→ 后端鉴权
```

首期默认ALL_PORTAL。

## 7. 应用访问

用户端用户 → 判断应用适用用户 → DIRECT/BIND/REQUEST → 检查入口资格/映射 → SSO进入子系统 → 子系统自行校验业务权限。

本地管理员默认不参与普通应用访问链路；未来如需要可按用户类别和应用规则扩展。

## 8. 公告

DRAFT → PUBLISHED 或 SCHEDULED → 到时PUBLISHED → 可WITHDRAWN/EXPIRED。PUBLISHED允许编辑。失效时间为空永久有效。

## 9. 待办/消息

子系统PUSH到门户；门户聚合展示；业务处理仍跳回子系统。

## 10. 组织

政务组织优先来源闽政务；本地用户组织可选；公众用户不强制组织。

## 11. 异常日志

OPEN → 管理员处理 → RESOLVED。
