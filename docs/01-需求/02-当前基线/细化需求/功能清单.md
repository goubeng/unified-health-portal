## 首期不纳入

- 公众/政务身份完整生命周期管理；
- 面向公众开放门户本地账号自助注册；
- 子系统业务角色、菜单、数据权限集中管理；
- 门户直接创建子系统业务账号；
- 复杂组织/应用数据范围；
- 我的应用收藏；
- 复杂 APM / 主机监控 / 链路追踪；
- 短信费用统计。
