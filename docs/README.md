# 卫健XC统一门户 · 文档中心

> 当前目标设计：V20260920-03  
> 本文件是项目人工文档唯一入口。

## 目录规范

- `01-需求/`：原始需求、当前需求基线、需求变更、接入资料、历史版本。
- `02-开发/`：开发设计、评审验收、下一阶段计划、过程记录。
- `03-交付/`：仅保存最终冻结并准备交付的成套文档。

## 当前权威顺序

1. 当前确认的产品决策/ADR；
2. `01-需求/02-当前基线`；
3. `02-开发/01-设计`；
4. `02-开发/03-计划`；
5. 历史需求、过程记录和历史评审。

## 管理原则

需求变更确认后必须同步回当前基线；开发计划完成后必须同步设计和评审；开发中的草稿不得直接作为交付文档。

`.project/`继续作为工程元数据目录，`database/`继续保存数据库源文件和Migration，不并入人工文档目录。
