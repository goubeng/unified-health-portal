## 5. 原始需求与历史追溯

### 5.1 已废止的用户体系旧方案

《统一门户用户体系场景与边界方案 V1.0.md》已完成有效内容吸收，**不再作为当前需求、设计、开发或验收依据**。

其仍有价值的内容已经分别并入：

- 主《卫健统一门户系统需求规格说明书》；
- 《登录与用户体系》；
- 《业务流程》；
- 《字段规则》；
- 《应用接入资料清单》；
- 相关权限、状态机和数据设计文档。

旧方案中的以下口径已被现行设计替代，不得继续引用：

- 将 LOCAL 作为第三类普通门户访问用户；
- 由 `unified_user` 同时承载用户端身份与管理端角色；
- 外部用户直接因“有角色”进入管理端，而不经过独立 `portal_admin_user` 管理授权主体；
- 纳管系统数量仍待确认，或使用43个/约43个子系统作为当前建设口径。

**目标模型**仍为 CITIZEN/GOV 门户访问主体 + 独立 `portal_admin_user` 管理授权主体 + 42 个子系统账号映射；**现行演示**的管理属性仍由用户运行实体及其数据库镜像承载，未完成独立 `portal_admin_user` 物理读写及真实凭证认证。不得把目标实体误写成已上线的实际存储结构。

### 5.2 原始材料保留

原始客户/项目材料保留在：

- `01-需求/01-原始需求/`

需求演进和历史版本不再通过复制需求规格说明书文件维护，统一通过：
