# 字段规则（V1.0）

## 1. 身份来源与用户类别

固定映射：

| 身份来源 | 用户类别编码 | 用户类别 |
|---|---|---|
| 闽政通 | CITIZEN | 公众用户 |
| 闽政务 | GOV | 政务用户 |

身份来源和用户类别均属于只读身份属性，不通过门户角色修改。

## 2. 角色字段

门户角色只保存门户RBAC信息：

- role_code
- role_name
- description
- status
- permissions
- data_scope

角色中不得保存“公众/政务”作为角色值，也不得保存子系统业务角色。

## 3. 用户/组织

用户：统一身份ID、账号、姓名、用户类别、身份来源、组织、门户启用状态、门户角色、首次登录、最近登录。

政务用户组织优先来源闽政务；公众用户组织允许为空。

## 4. 应用

access_mode：DIRECT / BIND / REQUEST。

适用用户类型与门户角色分开。

## 5. 应用访问申请

申请编号、应用ID、申请人ID、组织ID、原因、状态、提交时间、审核人、审核时间、审核意见、版本。

## 6. 公告

- status：DRAFT / SCHEDULED / PUBLISHED / WITHDRAWN / EXPIRED
- publish_mode：IMMEDIATE / SCHEDULED
- scheduled_publish_at：计划发布时间
- published_at：实际发布时间
- effective_end：失效时间；NULL=永久有效
- submitted_at / submitted_by：提交信息

## 7. 字典

最终应用系统分类使用业务字典配置。

系统状态和协议属于受控字典，不允许通过页面自由新增未被代码支持的新值。

## 8. 日志

数据库编码：

- SUCCESS / FAILURE / DENIED
- USER / APPLICATION / SYSTEM / ANONYMOUS

页面中文显示，不修改物理编码。

时间标题：

- 登录日志 → 登录时间
- 应用访问日志 → 访问时间
- 门户操作日志 → 操作时间
- 接口调用日志 → 调用时间
- 异常日志 → 发生时间

## 9. 运行监控

每个SSO/TODO/MESSAGE服务独立保存status。前端详情不再显示额外聚合status。
