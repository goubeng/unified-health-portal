# 字段规则（V1.0）

## 通用
- 数据库存稳定编码，前端显示中文；
- 启停字段统一“启用状态”；
- 时间字段按业务语义显示，不机械显示“创建时间”；
- 敏感字段脱敏；
- 枚举展示统一走字典/label层；
- 状态机枚举不得由普通字典自由扩展。

## 用户/组织
用户：统一身份ID、账号、姓名、用户类别、身份来源、组织、启用状态、首次登录、最近登录。  
组织：组织编码、名称、上级组织、类型、层级、路径、来源、排序、启用状态、备注。

## 应用
新增访问模式：DIRECT / BIND / REQUEST。启用状态与运行状态分开。

## 应用访问申请
申请编号、应用ID、申请人ID、组织ID、原因、状态、提交时间、审核人、审核时间、审核意见、版本。

## 公告
- status：DRAFT / SCHEDULED / PUBLISHED / WITHDRAWN / EXPIRED
- publish_mode：IMMEDIATE / SCHEDULED
- scheduled_publish_at：计划发布时间
- published_at：实际发布时间
- effective_end：失效时间；NULL=永久有效
- submitted_at / submitted_by：提交信息

原 effective_start 不再作为页面“生效时间”主字段。

## 日志
数据库result：SUCCESS / FAILURE / DENIED；actor_kind：USER / APPLICATION / SYSTEM / ANONYMOUS。前端对应中文：成功/失败/拒绝；用户/应用/系统/匿名。

时间标题：
- login/auth → 登录时间/认证时间
- access → 访问时间
- operation → 操作时间
- api → 调用时间
- error → 发生时间

## 运行监控
每个服务独立保存status。前端聚合页面不再额外展示无业务必要的综合“状态”。

## 字典
业务字典值使用稳定编码，Label使用中文。禁止仅通过字典增加程序尚不支持的状态或协议。
