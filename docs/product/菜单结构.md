# 菜单结构

> 项目：卫健XC统一门户系统  
> 阶段：P2  
> 原型策略：DEMO优先，Vue3 + Vite + TDesign Vue Next

## 1. 登录端

登录端不设置传统侧边菜单。

```text
统一登录
├─ 公众用户
│  ├─ 扫码登录
│  └─ 手机号验证码登录
└─ 政务用户
   ├─ 扫码登录
   └─ 手机号验证码登录
```

- 统一登录页：`/login`
- 认证结果页：`/auth/result`
- 上层已认证进入：由回调/凭证校验直接进入 `/portal/home`

## 2. 用户端门户

```text
统一应用门户
├─ 首页
├─ 应用中心
│  └─ 我的应用与其他应用（同页分区）
├─ 待办任务
├─ 消息中心
├─ 通知公告
└─ 个人中心
```

| 一级菜单 | 二级菜单 | 路由 | DEMO优先级 |
|---|---|---|---|
| 首页 | - | `/portal/home` | P0 |
| 应用中心 | 我的应用与其他应用 | `/portal/apps/all`（/mine兼容） | P0 |
| 待办任务 | - | `/portal/todos` | P0 |
| 消息中心 | - | `/portal/messages` | P0 |
| 通知公告 | - | `/portal/announcements` | P0 |
| 个人中心 | - | `/portal/profile` | P1 |

说明：
- “我的应用”不提供收藏能力。
- 原始清单43项，划除“财务薪酬管理系统”后42项纳入应用目录。
- 待办和消息均由子系统主动PUSH进入门户。

## 3. 平台管理端

```text
统一门户管理平台
├─ 首页
├─ 应用管理
│  ├─ 应用列表
│  ├─ 系统分类
│  └─ 应用接入配置
├─ 身份与映射
│  ├─ 统一身份索引
│  ├─ 闽政通/闽政务身份映射
│  ├─ 子系统账号映射
│  └─ 映射异常
├─ 门户权限
│  ├─ 门户角色
│  └─ 门户权限配置
├─ 业务集成
│  ├─ SSO接入
│  ├─ 待办接入
│  └─ 消息接入
├─ 公共服务接入（条件）
├─ 通知公告
├─ 配置管理
├─ 门户用户
├─ 运行监控
└─ 日志审计
   ├─ 登录/认证日志
   ├─ 应用访问日志
   ├─ 门户操作日志
   ├─ 接口调用日志
   └─ 异常日志
```
