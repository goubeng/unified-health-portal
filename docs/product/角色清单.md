# 角色清单

> 项目：卫健XC统一门户系统  
> 当前阶段：P3  
> 当前口径：用户类型与门户内部权限范围分层表达

2026-09-18 P4整改补充：界面认证来源明确称“闽政通 / 闽政务”；门户类别仅普通用户/门户管理员。新增门户用户访问状态与权限维护，不编辑来源身份资料或密码，不授予子系统业务权限。

## 2. 门户管理员权限范围

以下不是独立“用户类型”，而是门户管理员可获得的职责权限范围。一个门户管理员可以同时拥有多个权限范围。

| 权限范围 | 主要职责 | 当前定位 |
|---|---|---|
| 超级管理权限 | 门户全局配置、门户角色与权限、系统级设置 | 门户内部权限范围 |
| 应用管理权限 | 应用登记、分类、基础接入信息维护 | 门户内部权限范围 |
| 集成管理权限 | SSO、待办PUSH、消息PUSH、外部公共服务接入、运行监控 | 门户内部权限范围 |
| 公告管理权限 | 门户通知公告新增、编辑、发布、撤回、附件管理 | 门户内部权限范围 |
| 审计权限 | 登录、访问、操作、接口、异常日志查询 | 门户内部权限范围 |
| 身份映射权限 | 统一身份索引查看、上层身份映射、子系统账号映射、异常处理 | 门户内部权限范围 |

## 4. 已确认边界

- 门户管理员是管理端用户总称，不等同于一个固定的“超级管理员”角色。
- 应用管理员、集成管理员、公告管理员、审计管理员等旧称不再作为独立用户类型；对应能力改为“门户管理员（XX权限）”。
- 不单独设置固定“短信管理员”。若门户需要参与上层短信服务接入，由“门户管理员（集成管理权限）”承担。
- 门户角色与权限只管理门户自身菜单、页面、操作和门户数据范围。
- 门户不管理子系统业务角色、菜单权限和数据权限。
- 门户不拥有用户主数据管理权，不提供上层身份资料、密码等主数据维护。
- 子系统开户、业务授权和业务审批仍由各子系统负责。
