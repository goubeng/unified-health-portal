# 角色清单（V1.0）

## 用户类型
- 公众用户：通过公众侧上层身份平台认证。
- 政务用户：通过政务侧上层身份平台认证。
- 门户普通用户：登录后使用门户用户端功能。
- 门户管理员：可进入管理端，具体权限由系统角色决定。

## 门户系统角色
系统角色是可配置RBAC对象。建议内置：
- 门户超级管理员
- 应用管理角色
- 集成管理角色
- 公告管理角色
- 身份映射管理角色
- 审计角色

同一用户可拥有多个系统角色。

## 权限结构
每个角色配置菜单权限、页面权限、操作权限和门户数据范围。数据范围支持 SELF、ORG、ORG_AND_CHILDREN、ASSIGNED_APPS、ALL_PORTAL。

## 禁止事项
门户角色不得授予或修改子系统内部业务角色、业务菜单和业务数据权限。
