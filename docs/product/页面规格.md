# 页面规格（V1.0）

> 基线：V20260920-03。

## PG-001 统一登录

### 用户端登录

- 公众用户：闽政通；
- 政务用户：闽政务；
- 扫码/手机号等具体能力按外部身份源接口；
- 手机滑块删除下方“按住滑块向右拖动/已通过人机验证”图标与文字。

### 管理端登录

新增门户本地账号密码登录：

字段：
- 登录账号
- 密码
- 验证码/滑块（按最终安全方案）
- 登录按钮

规则：
- 用户必须为LOCAL来源；
- 账号必须启用且未锁定；
- 密码校验通过；
- 必须拥有有效管理角色；
- 首次登录可强制改密。

后续允许闽政务/闽政通用户认证后，若拥有门户管理角色直接进入管理端。

## PG-002 认证结果

覆盖：
- 登录成功；
- 认证失败；
- 账号停用；
- 账号锁定；
- 无管理权限；
- 外部认证异常；
- Session建立失败。

## PG-101 用户首页

用户端默认面向CITIZEN/GOV。顺序：待办 → 公告 → 消息 → 我的应用。Loading结束前不得显示Empty。

## PG-102/103 应用中心

根据用户类别、应用适用范围、访问模式和入口资格决定按钮：

- 进入应用；
- 关联账号；
- 申请使用；
- 查看申请。

LOCAL首期不默认参与普通应用中心业务。

## PG-108 个人中心

外部用户展示：
- 统一身份ID
- 姓名
- 用户类别
- 身份来源
- 所属组织
- 首次/最近登录
- 关联应用

身份来源/用户类别只读。

LOCAL如未来开放普通用户端，再复用该页面。

## PG-201 管理首页

面向拥有门户管理角色的用户。

显示：
- 应用总数/启用/正常/异常；
- 用户数；
- 待审核应用申请；
- 映射异常；
- 未处理异常日志；
- SSO/TODO/MESSAGE运行；
- 管理待办；
- 快捷入口。

## PG-205~208 身份与子系统映射

身份来源显示：
- 闽政通
- 闽政务
- 门户本地

LOCAL通常无子系统映射；页面允许显示“无映射需求”，不得制造虚假映射。

## PG-209 角色管理

### 默认角色

仅预置：
- 门户超级管理员
- 门户管理员

### 基本信息

- 角色编码
- 角色名称
- 说明
- 启用状态
- 关联用户数

### 权限

菜单 → 页面 → 操作。

第一阶段不强制提供复杂数据范围UI；默认角色使用ALL_PORTAL。

可保留未来“自定义角色”能力，但不预置应用/公告/审计等细分角色。

## PG-220 公告管理

支持草稿、提交、立即/定时发布、预览、Word导入、正文插图、附件、已发布编辑、撤回、撤回/失效删除、永久有效。

## PG-222 运行监控

仅按SSO/TODO/MESSAGE显示真实服务状态。删除额外综合状态。

## PG-223 登录/认证日志

字段：
- 登录时间
- 登录用户
- 登录账号
- 用户类别
- 身份来源
- 登录来源
- 登录方式
- 登录结果
- 失败原因
- IP
- 客户端
- 请求ID

LOCAL：
- 用户类别=门户本地用户
- 身份来源=门户本地
- 登录方式=账号密码

## PG-228 用户管理

### 查询

- 姓名/账号
- 用户类别
- 身份来源
- 所属组织
- 门户角色
- 启用状态

### 列表

- 序号
- 用户账号
- 姓名
- 用户类别
- 身份来源
- 所属组织
- 门户角色
- 启用状态
- 最近登录
- 操作

### 外部用户操作

允许：
- 查看
- 门户启停
- 分配门户角色（仅授权人员）
- 维护门户组织索引（必要时）

不允许修改：
- 闽政通/闽政务来源
- CITIZEN/GOV
- 权威姓名/手机号/账号

### 本地用户操作

超级管理员可：
- 新建
- 编辑门户资料
- 启停
- 分配角色
- 重置密码
- 解除锁定

密码、密码Hash不得出现在列表/详情/API响应中。

## PG-229 组织管理

政务用户组织优先闽政务；LOCAL组织可选；公众用户不强制组织。

组织首期主要用于资料、公告范围和查询，不作为复杂RBAC数据范围的首期前置条件。

## PG-230 字典管理

承接应用系统分类、公告类型、组织类型等业务字典。

## PG-231 应用访问申请

管理员审核门户入口资格，不审核子系统业务角色。

## 全局加载与UI

- 未初始化：Loading；
- 成功0条：Empty；
- 失败：Error + 重试；
- Dialog垂直居中；
- 13px基准字号；
- TDesign默认合理尺寸；
- 详情不叠加无意义外层卡片。
