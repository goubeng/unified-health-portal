# 业务对象清单

> P1 只定义业务对象及职责，不定义数据库表、字段类型、主外键、索引和 Migration。

| 编号 | 业务域 | 业务对象 | 说明 | 权威来源/归属 |
|---|---|---|---|---|
| O-01 | 身份 | 身份源 | 公众侧、政务侧等身份来源定义 | 上层平台/门户配置 |
| O-02 | 身份 | 统一身份索引 | 用于跨系统识别同一人的最小身份索引 | 门户维护，上层身份为权威 |
| O-03 | 身份 | 上层身份映射 | 统一身份与上层身份之间的映射 | 门户 |
| O-04 | 身份 | 登录Session | 门户登录会话 | 门户 |
| O-05 | 应用 | 门户应用/业务子系统 | 约43个系统的应用目录对象 | 门户登记，业务能力归子系统 |
| O-06 | 应用 | 应用分类 | 应用分类与排序 | 门户 |
| O-07 | 映射 | 子系统账号映射 | 统一身份与子系统账号关系 | 门户维护映射，账号权威在子系统 |
| O-08 | 映射 | 映射异常 | 冲突、重复、匹配失败等异常 | 门户 |
| O-09 | 权限 | 门户角色 | 门户自身角色 | 门户 |
| O-10 | 权限 | 门户权限 | 门户菜单、页面、操作、门户自身数据查看权限 | 门户 |
| O-11 | 待办 | 聚合待办 | 来自约43个子系统的待办 | 业务状态权威在子系统 |
| O-12 | 消息 | 聚合消息 | 子系统消息 + 门户自身消息 | 子系统/门户 |
| O-13 | 公告 | 门户通知公告 | 仅门户创建、发布、撤回 | 门户 |
| O-14 | 集成 | SSO接入配置 | 子系统单点登录配置 | 门户 |
| O-15 | 集成 | 待办接入配置 | 子系统PUSH接收、字段/状态映射、幂等与失败处理；不轮询子系统 | 门户 |
| O-16 | 集成 | 消息接入配置 | 子系统PUSH接收、类型映射、去重与失败处理；不轮询子系统 | 门户 |
| O-17 | 外部公共服务 | 公共服务接入配置（条件） | 上层短信等公共服务的必要接入信息；仅在门户参与调用链路时启用 | 上层平台为能力权威，门户仅保存必要接入配置 |
| O-18 | 外部公共服务 | 公共服务调用记录（条件） | 门户实际参与调用时记录必要结果和审计摘要，不替代上层发送明细 | 门户/上层公共服务平台 |
| O-19 | 外部公共服务 | 公共服务异常记录（条件） | 记录调用超时、失败、未知结果等异常 | 门户 |
| O-21 | 配置 | 系统配置 | 登录、接口、消息、监控等参数 | 门户 |
| O-22 | 监控 | 服务/接口运行状态 | 身份平台、SSO、待办、消息及已确认的上层公共服务状态 | 门户采集/派生 |
| O-23 | 审计 | 登录/认证日志 | 登录与认证结果 | 门户 |
| O-24 | 审计 | 应用访问日志 | 应用访问与SSO结果 | 门户 |
| O-25 | 审计 | 门户操作日志 | 管理端关键操作 | 门户 |
| O-26 | 审计 | 接口调用日志 | 集成接口调用 | 门户 |
| O-27 | 审计 | 异常日志 | 门户与集成异常 | 门户 |

## 边界说明

- 统一身份索引不是第三套完整用户中心。
- 子系统账号映射只保存映射关系，不改变账号归属。
- 聚合待办不重新实现子系统业务审批。
- 门户通知公告不汇聚子系统公告。
- 是否独立建表及具体关系模型留待 P3。

- 短信渠道、短信模板、费用核算不再作为当前门户固定业务对象；现有P3相关物理结构暂按条件预留处理，待上层公共服务方案确认后决定保留或移除。
