# 范围边界（V1.0）

> 基线：V20260920-02。本文件描述下一阶段目标范围，不代表当前代码全部完成。

## 1. 三层边界

### 身份来源层

- 闽政通：公众用户身份来源。
- 闽政务：政务用户身份来源。

身份来源层提供权威认证和身份资料。

### 卫健统一门户

门户是中间层，负责：

- 认证结果承接；
- 最小统一身份索引；
- 用户类别和身份来源记录；
- 门户用户状态；
- 门户角色和门户权限；
- 门户组织索引；
- 应用目录和应用入口资格；
- 应用访问申请；
- 子系统账号映射；
- 待办/消息聚合；
- 门户公告；
- SSO/TODO/MESSAGE配置；
- 运行监控；
- 日志审计；
- 配置与字典。

### 业务子系统层

各子系统负责：

- 子系统账号；
- 开户；
- 子系统业务角色；
- 子系统菜单权限；
- 子系统数据权限；
- 子系统业务审批。

## 2. 权限边界

- 公众/政务是用户类别，不是门户角色。
- 闽政通/闽政务是身份来源，不是门户角色。
- 门户系统角色只控制门户中间层。
- 门户应用访问授权只代表入口资格。
- 子系统业务授权仍由子系统负责。

## 3. 组织边界

政务用户组织优先来自闽政务。公众用户不强制存在组织。门户只维护组织索引，不取代权威组织源。

## 4. 字典边界

应用系统分类、公告类型、组织类型等可进入业务字典。

系统状态、运行状态、协议等仅允许受控配置Label、排序、启停，不允许通过字典增加程序未实现的新状态或协议。
