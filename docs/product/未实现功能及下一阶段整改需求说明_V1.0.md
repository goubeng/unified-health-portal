## 1. 最新身份与权限结论

最终身份来源调整为三类：

```text
闽政通 → 公众用户
闽政务 → 政务用户
门户本地 → 门户本地用户
```

用户类别与门户角色必须分开。

默认门户角色只保留：

```text
门户超级管理员
门户管理员
```

不再预置应用管理员、集成管理员、公告管理员、映射管理员、审计管理员等细分角色。

RBAC菜单/页面/操作能力仍保留，未来按实际人数和分工扩展。

## 3. 本地账号方案

### 使用场景

主要面向：
- 项目维护人员；
- 系统管理员；
- 运维人员；
- 不具备闽政通/闽政务账号的门户维护人员。

### 首期限制

- 不开放用户自助注册；
- 仅超级管理员创建本地账号；
- 默认用于管理端；
- 没有管理角色不得进入管理端；
- 本地用户不自动参与普通应用访问。

### 安全要求

- 密码Hash保存；
- 禁止明文；
- 初始密码不入Git；
- 支持首次改密；
- 支持失败计数/锁定；
- 支持超级管理员重置密码；
- 登录/失败/重置必须写审计日志。

## 4. 角色管理简化

### 默认角色

#### 门户超级管理员

全部管理能力，特别是：
- 用户/本地管理员；
- 角色权限；
- 系统配置；
- 其它全部业务管理。

#### 门户管理员

承担绝大多数日常维护：
- 应用；
- 应用申请；
- 公告；
- 映射；
- 组织/字典；
- 监控；
- 日志。

### 权限实现

首期：
- MENU
- PAGE
- ACTION
- 默认ALL_PORTAL

后续再考虑：
- ASSIGNED_APPS
- ORG
- ORG_AND_CHILDREN
- 自定义角色

## 5. 用户管理改造

统一用户列表加入：

- 用户账号
- 姓名
- 用户类别
- 身份来源
- 所属组织
- 门户角色
- 启用状态
- 最近登录

用户类别：
- 公众用户
- 政务用户
- 门户本地用户

LOCAL操作：
- 新建
- 编辑门户资料
- 启停
- 分配角色
- 重置密码
- 解锁

外部用户不得修改权威身份资料。

- 闽政通

- 门户本地账号密码

- 闽政务/闽政通认证用户拥有管理角色后进入管理端。

## 7. 应用访问申请

继续按：
- DIRECT
- BIND
- REQUEST

申请只授予门户入口资格，不授予子系统业务权限。

## 8. 组织管理

- 政务用户组织优先闽政务；
- LOCAL组织可选；
- 公众用户不强制组织；
- 首期组织不承担复杂RBAC数据范围。

## 9. 字典管理

最终由字典管理承接：
- 应用系统分类；
- 公告类型；
- 组织类型。

系统状态/协议为受控字典。

## 10. 公告升级

- 已发布可编辑；
- 已撤回/已失效可删除；
- 保存=草稿；
- 提交=发布设置；
- 立即发布；
- 定时发布；
- SCHEDULED状态；
- 失效时间为空永久有效；
- 预览；

- 正文插图。

3. 管理端所有写操作服务端二次鉴权；
4. 本地密码相关日志不得写入密码或Hash；
5. 目标文档未落地前不得标记为已实现；
6. 历史P3/P4验收事实保留，不回写成当前目标已完成。
