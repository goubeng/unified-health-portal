# P3 数据字典（设计 v0.1.0）

状态：DESIGN_NOT_APPLIED。目标 PostgreSQL 14；现网引擎/版本未验证。与 nocodb-schema.json 同源；NocoDB UI类型不等于底层SQL类型。业务ID使用text UUID（种子配置ID为稳定键），Provider映射真实NocoDB记录ID。时间存timestamptz UTC，展示Asia/Shanghai。状态变化必须遵守状态机和Service动作，不能直接通用update状态。
