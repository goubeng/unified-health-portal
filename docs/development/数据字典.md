# 数据字典（V1.0目标增量）

> 以下结构在Migration完成前属于目标设计。

## portal_organization
| 字段 | 类型 | 说明 |
|---|---|---|
| id | text | 稳定ID |
| code | text | 门户组织编码 |
| name | text | 组织名称 |
| parent_id | text/null | 上级组织 |
| org_type | text | 组织类型 |
| level | bigint | 层级 |
| path | text | 稳定路径 |
| source_code | text | 权威来源 |
| source_org_key | text | 上层组织稳定ID |
| sort_order | bigint | 排序 |
| status | text | ENABLED/DISABLED |
| remark | text/null | 备注 |
| created_at/updated_at | timestamptz | 时间 |
| version | bigint | 乐观版本 |

## application.access_mode
DIRECT / BIND / REQUEST。

## application_access_request
id、request_no、application_id、user_id、org_id、reason、status、submitted_at、reviewed_by、reviewed_at、review_note、version。

## application_access_grant
id、application_id、user_id、request_id、status、granted_by、granted_at、expires_at、revoked_at、version。

## announcement调整
新增 publish_mode、scheduled_publish_at、submitted_at、submitted_by。status：DRAFT / SCHEDULED / PUBLISHED / WITHDRAWN / EXPIRED。effective_end=NULL表示永久有效。

## dict_type
code、name、description、editable、status、sort_order、version。

## dict_item
type_id、label、value、sort_order、status、remark、system_locked、version。

## audit_event调整
保留 kind、event_code、request_id、actor_user_id、actor_kind、application_id、object_type、object_id、result、summary、details、resolution_status。可选新增 resolved_by、resolved_at、resolution_note。

## 枚举
- enable_status：ENABLED / DISABLED
- access_mode：DIRECT / BIND / REQUEST
- application_request_status：PENDING / APPROVED / REJECTED / WITHDRAWN / EXPIRED
- application_grant_status：ACTIVE / REVOKED / EXPIRED
- announcement_status：DRAFT / SCHEDULED / PUBLISHED / WITHDRAWN / EXPIRED
- publish_mode：IMMEDIATE / SCHEDULED
- audit_result：SUCCESS / FAILURE / DENIED
- runtime_status：NORMAL / ABNORMAL / UNCONFIGURED / DISABLED
