# 数据字典（V1.0目标增量）

> 基线：V20260920-02。以下为下一阶段目标结构；Migration完成前不能视为已落库。

## 身份语义

| 概念 | 值 | 说明 |
|---|---|---|
| 身份来源 | 闽政通 | 公众用户权威身份来源 |
| 身份来源 | 闽政务 | 政务用户权威身份来源 |
| user_type | CITIZEN | 公众用户 |
| user_type | GOV | 政务用户 |

身份来源与user_type不得由portal_role修改。

## portal_organization

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text | 稳定ID |
| code | text | 门户组织编码 |
| name | text | 组织名称 |
| parent_id | text/null | 上级组织 |
| org_type | text | 组织类型 |
| level | bigint | 层级 |
| path | text | 稳定路径 |
| source_code | text | 来源标识；政务组织主要对应闽政务 |
| source_org_key | text | 来源平台稳定组织ID |
| sort_order | bigint | 排序 |
| status | text | ENABLED/DISABLED |
| remark | text/null | 备注 |
| version | bigint | 乐观版本 |

公众用户组织字段允许为空。

## application.access_mode

DIRECT / BIND / REQUEST。

## application_access_request

id、request_no、application_id、user_id、org_id、reason、status、submitted_at、reviewed_by、reviewed_at、review_note、version。

状态：PENDING / APPROVED / REJECTED / WITHDRAWN / EXPIRED。

## application_access_grant

id、application_id、user_id、request_id、status、granted_by、granted_at、expires_at、revoked_at、version。

状态：ACTIVE / REVOKED / EXPIRED。

该对象仅表示门户入口资格。

## announcement调整

新增publish_mode、scheduled_publish_at、submitted_at、submitted_by。

status：DRAFT / SCHEDULED / PUBLISHED / WITHDRAWN / EXPIRED。

effective_end=NULL表示永久有效。

## dict_type / dict_item

业务字典最终承接：

- 应用系统分类；
- 公告类型；
- 组织类型。

系统状态和协议属于受控字典，禁止自由增加代码未支持值。

## audit_event

保留kind、event_code、request_id、actor_user_id、actor_kind、application_id、object_type、object_id、result、summary、details、resolution_status。

details应允许保存：

- userType
- identitySource
- loginSource
- loginMethod
- module
- page
- errorCode
- ip
- client

可选新增resolved_by、resolved_at、resolution_note。

## 主要枚举

- enable_status：ENABLED / DISABLED
- access_mode：DIRECT / BIND / REQUEST
- application_request_status：PENDING / APPROVED / REJECTED / WITHDRAWN / EXPIRED
- application_grant_status：ACTIVE / REVOKED / EXPIRED
- announcement_status：DRAFT / SCHEDULED / PUBLISHED / WITHDRAWN / EXPIRED
- publish_mode：IMMEDIATE / SCHEDULED
- audit_result：SUCCESS / FAILURE / DENIED
- runtime_status：NORMAL / ABNORMAL / UNCONFIGURED / DISABLED
