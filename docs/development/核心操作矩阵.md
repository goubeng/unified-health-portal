# 核心操作矩阵（V1.0）

| 操作 | 主体 | 权限 | 核心校验 | 结果 |
|---|---|---|---|---|
| 分配用户角色 | 门户管理员 | 用户/角色管理 | 角色启用、不得锁死自身超级权限 | 用户角色变化 |
| 配置角色权限 | 门户管理员 | 超级管理 | 权限存在、数据范围合法 | 角色权限变化 |
| 维护组织 | 门户管理员 | 组织管理 | 编码唯一、父级合法、无循环 | 组织树变化 |
| 提交应用申请 | 用户本人 | 已登录 | 应用可申请、无重复PENDING/有效授权 | PENDING |
| 撤回申请 | 用户本人 | 本人 | 当前PENDING | WITHDRAWN |
| 审核通过 | 管理员 | 应用审核 | PENDING、应用存在 | APPROVED + ACTIVE授权 |
| 审核驳回 | 管理员 | 应用审核 | PENDING | REJECTED |
| 保存公告 | 公告管理员 | 公告编辑 | 内容校验 | DRAFT |
| 提交立即发布 | 公告管理员 | 公告发布 | 草稿完整 | PUBLISHED |
| 提交定时发布 | 公告管理员 | 公告发布 | 计划时间>当前 | SCHEDULED |
| 定时发布任务 | SYSTEM | system | 到达计划时间 | PUBLISHED |
| 编辑已发布公告 | 公告管理员 | 公告编辑 | 当前PUBLISHED | 保持PUBLISHED |
| 撤回公告 | 公告管理员 | 公告撤回 | 当前PUBLISHED | WITHDRAWN |
| 删除撤回/失效公告 | 公告管理员 | 公告删除 | WITHDRAWN/EXPIRED | 归档删除 |
| 维护字典 | 超级管理员 | 字典管理 | system_locked规则 | 字典更新 |
| 标记异常已处理 | 审计/集成管理员 | 异常处理 | ERROR且OPEN | RESOLVED |

所有写操作必须服务端二次鉴权、版本校验并写审计事件。
