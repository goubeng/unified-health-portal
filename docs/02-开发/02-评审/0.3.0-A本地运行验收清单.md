# 0.3.0-A 本地运行验收清单

> 状态：待执行

## 1. 启动前确认

- 当前分支：main；
- 拉取最新代码；
- Node.js 20.19+ 或 22 LTS；
- 本次验收不需要启动PostgreSQL/NocoDB；
- 不执行database/migrations、database/schema、database/seed。

## 2. 启动

终端1：

```bash
npm run api
```

启动日志必须包含：

```text
repository=MEMORY
```

不得显示DATABASE。

可访问：

```text
http://127.0.0.1:3801/api/portal/health
```

期望关键结果：

```json
{
  "repository": "MEMORY_A",
  "database": null,
  "schema": null,
  "phase": "0.3.0-A"
}
```

终端2：

```bash
npm run dev
```

打开：

```text
http://127.0.0.1:3800
```
