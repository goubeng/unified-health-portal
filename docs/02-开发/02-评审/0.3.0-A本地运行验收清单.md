# 0.3.0-A 本地运行验收清单

> 状态：待执行  
> 当前目标设计：V20260920-03  
> 目的：验证0.3.0-A前端Mock原型、Memory API与核心业务闭环。  
> 数据库边界：本轮不访问、不迁移、不清理PostgreSQL/NocoDB；数据库差异统一留到0.3.0-B。

## 1. 启动前确认

- 当前分支：main；
- 拉取最新代码；
- Node.js 20.19+或22 LTS；
- 本次验收不需要启动PostgreSQL/NocoDB；
- 禁止执行 `npm run api:db`；
- 禁止执行 `database/migrations`、`database/schema.sql`、`database/seed.sql`；
- 当前P3数据库结构仅作为历史验收事实，不以本清单判断其是否符合最新字段目标。

## 5. 用户端核心闭环

### 5.1 首页
- [ ] 我的待办、通知公告、消息、我的应用均可正常加载；
- [ ] 数据加载完成前只显示Loading，不先闪现Empty；
- [ ] 首页待办详情与待办任务页复用同一业务规则；
- [ ] 首页业务标题与应用名称当前原型样式一致，不影响正式需求口径。

### 5.2 应用中心
- [ ] DIRECT可直接进入；
- [ ] BIND未关联显示账号确认入口；
- [ ] REQUEST可提交访问申请；
- [ ] REQUEST_PENDING可查看处理中状态；
- [ ] REQUEST_REJECTED可重新申请；
- [ ] REVIEWING / FAILED / CONFLICT / ACCOUNT_DISABLED按当前结果展示下一步；
- [ ] 普通用户界面不暴露候选匹配、OTP、密码验证等底层技术过程；
- [ ] 用户页面不展示Mock/阶段研发术语。

### 5.3 应用访问与账号处理
- [ ] DIRECT路径可完成门户入口资格校验；
