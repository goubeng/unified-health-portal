## 4. B阶段启动时禁止反向修改的前端契约

B阶段数据库与 REST API 必须适配已经冻结的业务 DTO，不能为了兼容 P3 旧物理字段把页面改回旧模型：

- 不恢复 LOCAL 普通用户；
- 不恢复 scopes 作为正式权限字段；
- 不恢复 application.status/runtimeStatus 为页面权威字段；
- 不恢复 integration.configurationStatus/connectionStatus；
- 不恢复 TODO priority/dueAt/sourceRevision/terminalAt/EXPIRED；
- 不把 createdAt 重新解释为 TODO/MESSAGE 接收时间；
- 不把公告 SCHEDULED/EXPIRED 作为永久主状态；
- 不把单一 actor 重新作为正式 Session 返回模型。

## 5. 数据库安全边界

当前 **0.3.0-B 仍为 NOT_STARTED**。

- 不执行 `npm run api:db`；
