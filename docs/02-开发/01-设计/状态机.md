# 状态机（V1.0）

> 基线：V20260920-03。

## 1. 门户本地账号

门户用户启用状态：

```text
ENABLED ↔ DISABLED
```

登录锁定属于凭证安全状态，不改变用户启停状态：

```text
可登录
→ 连续失败达到阈值
→ 临时锁定
→ 到时自动解锁 / 超级管理员解锁
→ 可登录
```

密码：

```text
初始/重置密码
→ must_change_password=true
→ 用户修改密码
→ must_change_password=false
```

本地账号删除策略首期优先停用，不要求物理删除。

## 2. 门户角色

角色：
```text
ENABLED ↔ DISABLED
```

用户必须至少拥有一个有效管理角色才能进入管理端。

默认角色：
- SUPER_ADMIN
- PORTAL_ADMIN

## 3. 应用访问申请

```text
PENDING
├─ APPROVED
├─ REJECTED
└─ WITHDRAWN
```

授权：
```text
ACTIVE → REVOKED / EXPIRED
```

## 4. 公告

```text
DRAFT
├─ PUBLISHED
└─ SCHEDULED

SCHEDULED
├─ PUBLISHED
└─ DRAFT

PUBLISHED
├─ PUBLISHED
├─ WITHDRAWN
└─ EXPIRED
```

## 5. 子系统映射

UNBOUND → VERIFYING → BOUND / FAILED / CONFLICT。

BOUND可解绑回UNBOUND。

LOCAL首期默认无子系统映射需求。

## 6. 待办

PENDING → COMPLETED / WITHDRAWN / EXPIRED。

门户“去处理”不改变业务状态。

## 7. 消息

UNREAD → READ。

## 8. 异常日志

OPEN → RESOLVED。
