# 状态机（V1.0 目标）

> 目标设计：V20260921-01。

> **现行实现核对（2026-10-12）：**以下是目标状态机，不等同于全部已自动化接入。当前应用综合运行状态由 `src/services/portal.js` 派生：应用停用优先；SSO 始终必需，已启用的 TODO/MESSAGE 也纳入；必需能力按异常、停用、未配置的顺序优先判定，全部正常才显示“正常”。**已移除** `recordMonitorObservation` 人工检测命令和 `monitor:check` 权限；仅保留 `monitor:view` 及运行监控详情中的状态历史查看。应用启停或接入配置改变产生有效状态迁移时写入 `monitor_status_history`；当前没有正式连续失败阈值/真实自动健康检测器。

## 1. 状态分类

必须区分：
- 管理状态：管理员控制，例如 enabled；
- 配置状态：系统根据必要配置计算；
- 运行状态：系统检测产生。

正式目标中，运行状态应由真实健康检测器计算，不允许管理员直接“设为正常”。现行原型已取消人工“录入检测结果”，仅根据可用的应用/接入配置及已有模拟运行样本计算和展示，不能将其作为真实上下游健康证明。

## 2. 门户管理用户

```text
ENABLED ↔ DISABLED
```

停用只影响管理端授权，不影响绑定外部用户继续使用用户端。

最后一个有效 SUPER_ADMIN 不允许被停用、删除或移除角色。

## 3. 门户角色

```text
ENABLED ↔ DISABLED
```

停用角色不删除用户关系与权限配置，但不参与授权计算。

## 4. 应用

```text
ENABLED ↔ DISABLED
```

应用停用后不允许新发起 SSO；历史待办/消息/映射记录保留。

## 5. 接入能力

配置状态：
- UNCONFIGURED；
- CONFIGURED。

启用状态：
- ENABLED；
- DISABLED。

运行状态：
- UNCONFIGURED；
- DISABLED；
- NORMAL；
- ABNORMAL。

计算：
- 未配置 → UNCONFIGURED；
- 已配置但停用 → DISABLED；
- 已启用且检测成功 → NORMAL；
- 已启用且检测失败达到阈值 → ABNORMAL（仅正式自动检测目标；当前演示无阈值检测器，也不提供管理员人工观测录入入口）。

## 6. 子系统账号映射

```text
UNBOUND
→ VERIFYING
→ BOUND
   ↘
    REVIEWING → BOUND
VERIFYING/REVIEWING → FAILED
任意冲突 → CONFLICT
BOUND → UNBOUND（解绑）
```

子系统账号状态与映射状态分开。

## 7. TODO

首期：
- PENDING；
- COMPLETED；
- WITHDRAWN。

```text
PENDING → COMPLETED
PENDING → WITHDRAWN
```

终态原则上不回退。门户“去处理”不触发状态迁移。

## 8. MESSAGE

收件人状态：
- UNREAD → READ。

删除：
- deleted=false → true。

不物理删除消息本体。

## 9. 公告

主状态：
- DRAFT；
- PUBLISHED；
- WITHDRAWN。

发布方式：
- IMMEDIATE；
- SCHEDULED。

```text
DRAFT --立即/定时到点--> PUBLISHED
PUBLISHED --撤回--> WITHDRAWN
```

“定时发布”“已失效”可作为派生展示状态。

## 10. 二维码认证

- WAITING；
- SCANNED；
- CONFIRMED；
- EXPIRED；
- CANCELLED。

刷新二维码创建新会话，不重新激活已过期会话。

## 11. 状态责任

| 对象 | 状态 | 责任方 |
|---|---|---|
| 管理用户 | enabled | 门户管理员 |
| 角色 | enabled | 门户管理员 |
| 应用 | enabled | 门户管理员 |
| 接入配置状态 | configured | 系统计算 |
| 接入运行状态 | normal/abnormal | 系统检测 |
| TODO业务状态 | pending/completed/withdrawn | 来源子系统 |
| 消息已读 | unread/read | 当前用户 |
| 映射状态 | 映射流程 | 门户+子系统 |
| 公告 | draft/published/withdrawn | 门户管理员 |
