## portal_local_credential

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text | 主键 |
| user_id | text | LOCAL统一用户ID，唯一 |
| username | text | 本地登录账号，唯一 |
| password_hash | text | 密码Hash，仅服务端 |
| password_algorithm | text | Hash算法/版本 |
| must_change_password | boolean | 首次/重置后强制改密 |
| failed_login_count | bigint | 连续失败次数 |
| locked_until | timestamptz/null | 锁定截止时间 |
| password_updated_at | timestamptz | 密码更新时间 |
| last_login_at | timestamptz/null | 最近成功登录 |
| created_at | timestamptz | 创建时间 |
| updated_at | timestamptz | 更新时间 |
| version | bigint | 乐观版本 |

禁止API返回password_hash。

## portal_organization

LOCAL和CITIZEN用户的org允许为空。

政务用户组织优先映射闽政务组织稳定ID。

## application.account_binding_mode

- AUTO：可信唯一标识自动关联
- SELF：用户完成二次验证后自助关联
- REVIEW：用户验证后进入管理员审核
- ADMIN：管理员人工建立关联

## mapping_risk_level

- NORMAL
- HIGH

规则：

- NAME_PHONE表示候选匹配，不表示已经完成绑定；
- SUBSYSTEM_OTP只能发送至子系统原账号已登记手机号；
- application_id + external_user_id不得同时存在多个有效BOUND；
- 子系统账号状态与映射状态分离。

## todo_item（0.3.0-B目标）

目标字段只保留门户聚合待办所需最小集合。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text | 门户待办ID |
| application_id | text | 来源应用 |
| target_user_id | text | 接收用户 |
| source_todo_id | text | 来源系统待办ID |
| title | text | 待办标题 |
| summary/content | text/null | 待办说明 |
| business_type | text/null | 业务类型 |
| status | text | PENDING / COMPLETED / WITHDRAWN |
| source_created_at / received_at | timestamptz | 来源创建时间或门户接收时间 |
| business_url | text/null | 业务处理地址 |
| created_at | timestamptz | 门户创建时间 |
| updated_at | timestamptz | 最近更新时间 |
| version | bigint | 门户自身乐观锁（如保留） |

0.3.0-B 删除旧字段：

- priority；
- source_revision；
- due_at；
- terminal_at。

TODO不再使用EXPIRED状态，也不生成“逾期”信息。
