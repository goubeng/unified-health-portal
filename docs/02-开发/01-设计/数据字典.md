## todo_status

- PENDING

当前推送协议仍只接收上述三态，不接收 priority/dueAt。旧库存在的 EXPIRED 待办仅以禁用字典项展示，不开放新推送。

## 当前演示系统的业务字典配置（2026-09-29）

字典管理现有 6 类基础配置外，增加以下常用业务类型。表中值是数据库和接口的稳定编码；管理端可调整标签、排序和启停，但字典配置不扩充业务状态机。历史记录可继续按禁用项显示；需要用户选择的操作只允许业务规则支持且启用的值。

| 类型编码 | 用途 | 值 |
|---|---|---|
| todo_status | 待办状态 | PENDING、COMPLETED、WITHDRAWN；EXPIRED 仅历史展示 |
| todo_task_type | 待办任务类型 | 服务事项、材料补正、审核审批、结果确认；可扩展，已被待办引用的值不可改/删 |
| message_type | 消息类型 | SYSTEM、BUSINESS、TODO_REMINDER |
| message_read_status | 消息阅读状态 | UNREAD、READ |
| application_request_status | 应用申请状态 | PENDING、APPROVED、REJECTED、WITHDRAWN |
| account_opening_status | 账号开通状态 | PENDING、PROCESSING、COMPLETED |
| mapping_status | 账号关联状态 | UNBOUND、VERIFYING、REVIEWING、BOUND、FAILED、CONFLICT |
| announcement_status | 公告状态 | DRAFT、PUBLISHED、WITHDRAWN；SCHEDULED、EXPIRED 仅派生展示 |
| announcement_scope | 公告适用范围 | ALL、CITIZEN、GOV |
| publish_mode | 公告发布方式 | IMMEDIATE、SCHEDULED |

## permission

权限建议使用稳定编码，如：
- admin-user:view
- admin-user:edit
- role:permission-config
- application:edit
- integration:test
- monitor:check
- announcement:publish
- audit:view

## API 时间和空值

- API 时间：ISO 8601；
- 数据库存储 timestamptz；
- 不存在可选值使用 NULL；
- 前端无值展示 `-`，不得把展示占位写回数据库。
