## admin_auth_type

| 值 | 说明 |
|---|---|
| EXTERNAL | 绑定外部访问主体认证 |

## portal_admin_user

| 字段 | 说明 |
|---|---|
| id | 管理用户ID |
| account/display_account | 管理端展示账号 |
| name | 姓名 |
| auth_type | EXTERNAL/LOCAL |
| access_user_id | 绑定访问主体，可空 |
| enabled | 管理端访问启用 |
| protected_flag | 受保护账号标记 |
| last_login_at | 最近管理端登录 |
| version | 乐观版本 |

## portal_admin_credential

| 字段 | 说明 |
|---|---|
| admin_user_id | LOCAL 管理用户，唯一 |
| username | 本地账号，唯一 |
| password_hash | 服务端密码Hash |
| password_algorithm | 算法/版本 |
| must_change_password | 是否强制改密 |
| failed_login_count | 连续失败次数 |
| locked_until | 锁定截止 |
| password_updated_at | 密码更新时间 |

## todo_status

- PENDING
- COMPLETED
- WITHDRAWN

不再使用 EXPIRED，不接收 priority/dueAt。

## message_read_status

- UNREAD
- READ

消息删除采用 recipient.deleted，不增加 DELETE 业务状态。

## announcement_status

- DRAFT
- PUBLISHED
- WITHDRAWN

## publish_mode

- IMMEDIATE
- SCHEDULED

“定时发布/已失效”可根据 publish_mode、scheduled_publish_at、effective_end 派生展示。

## permission

权限建议使用稳定编码，如：
- admin-user:view
- admin-user:edit
- role:permission-config
- application:edit
- integration:test
- monitor:check
- announcement:publish
- audit:view

## API 时间和空值

- API 时间：ISO 8601；
- 数据库存储 timestamptz；
- 不存在可选值使用 NULL；
- 前端无值展示 `-`，不得把展示占位写回数据库。
