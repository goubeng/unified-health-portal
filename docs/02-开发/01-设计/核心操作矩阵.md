# 核心操作矩阵（V1.0）

> 基线：V20260920-03。

> **历史目标边界（2026-10-01）：**本矩阵保留原 V1.0 目标操作，不表示每行已在演示系统实现。尤其本地密码/解锁只需演示页面，不校验或保存真实凭证；子系统 OTP、原系统账号验证及自动关联也未完成真实上游接入。当前可执行动作与权限以 `src/services/portal.js`、`src/config/pages.js` 为准，不能仅凭本表认定上线能力。

| 操作 | 主体 | 首期角色 | 核心校验 | 结果 |
|---|---|---|---|---|
| 创建本地用户 | 管理员 | SUPER_ADMIN | 账号唯一、LOCAL、初始密码安全 | 新LOCAL用户 |
| 编辑本地资料 | 管理员 | SUPER_ADMIN | 不暴露凭证 | 用户更新 |
| 启停用户 | 管理员 | SUPER_ADMIN | 不能误锁唯一超级管理员 | 状态变化 |
| 重置本地密码 | 管理员 | SUPER_ADMIN | LOCAL用户、审计 | 强制改密 |
| 解锁本地账号 | 管理员 | SUPER_ADMIN | 当前锁定 | failed count清零 |
| 分配门户角色 | 管理员 | SUPER_ADMIN | 角色有效、保留至少一个超级管理员 | user_role变化 |
| 配置角色权限 | 管理员 | SUPER_ADMIN | 权限合法 | role_permission变化 |
| 日常门户维护 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | 菜单/页面/操作权限 | 业务数据变化 |
| 提交应用申请 | 用户 | CITIZEN/GOV | 应用REQUEST、无重复申请 | PENDING |
| 撤回应用申请 | 用户本人 | 本人 | PENDING | WITHDRAWN |
| 审核应用申请 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | PENDING | APPROVED/REJECTED |
| 自动关联子系统账号 | 系统 | 系统规则 | 可信唯一ID且唯一匹配、账号有效 | BOUND或转异常 |
| 自助关联子系统账号 | 用户本人 | CITIZEN/GOV | 候选账号+二次验证通过 | BOUND/REVIEWING |
| 子系统手机号OTP验证 | 用户本人 | CITIZEN/GOV | OTP发送到子系统原登记手机号 | PASSED/FAILED |
| 原系统账号一次性验证 | 用户本人 | CITIZEN/GOV | 凭据不落库、不写日志 | PASSED/FAILED |
| 审核高权限账号关联 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | REVIEWING、验证证据完整 | BOUND/FAILED |
| 管理员人工关联 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | 有人工依据、无重复有效绑定 | BOUND |
| 处理映射冲突 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | CONFLICT、禁止直接覆盖 | 保留/解绑/重绑 |
| 解绑子系统账号 | 用户/管理员 | 本人或管理角色 | 身份确认；高权限按策略审核 | UNBOUND |
| 保存公告 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | 内容校验 | DRAFT |
| 立即发布 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | 发布权限 | PUBLISHED |
| 定时发布 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | 时间合法 | SCHEDULED |
| 编辑已发布 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | PUBLISHED | 保持PUBLISHED |
| 撤回公告 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | PUBLISHED | WITHDRAWN |
| 删除撤回/失效公告 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | 状态合法 | 删除/归档 |
| 维护字典 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | system_locked | 字典更新 |
| 标记异常已处理 | 管理员 | PORTAL_ADMIN/SUPER_ADMIN | OPEN | RESOLVED |

## 强制规则

- 所有写操作服务端二次鉴权；
- 角色权限不能只靠前端隐藏；
- 本地密码/Hash不能进入审计details；
- 不允许通过portal_role修改CITIZEN/GOV/LOCAL；
- 不允许门户操作子系统业务角色。
