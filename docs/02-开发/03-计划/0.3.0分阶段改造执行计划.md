## B阶段：0.3.0-B 数据库与正式后端基础

### 启动前置
1. V20260921-01 前端 DTO 已冻结；
2. A阶段本地 test/build/浏览器验收通过并形成记录；
3. 数据库使用 P3 数据副本先演练；
4. 明确执行环境、Schema、备份与回滚方式。

### 目标模型
- unified_user：仅 CITIZEN/GOV 门户访问主体；
- portal_admin_user：独立管理端授权主体；
- portal_admin_credential：LOCAL 管理账号凭证；
- portal_admin_user_role：管理用户角色关系；
- portal_role / portal_permission / portal_role_permission：resource:action RBAC；
- application.enabled 与 application_integration 分离；
- TODO/MESSAGE/announcement/audit 按 V20260921-01 收口；
- 正式运行不再依赖 P4RUN_STATE 整包 JSON。

### Migration 顺序
不修改历史 001～004，新建：

1. 005_admin_domain.sql
2. 006_application_access.sql
3. 007_integration_model.sql
4. 008_business_projection_cleanup.sql
5. 009_audit_actor_upgrade.sql
6. 010_legacy_retirement.sql

每个 Migration 必须包含：
- 前置检查；
- 数据迁移；
- 约束/索引；
- 验证 SQL；
- 回滚/恢复说明。

### B阶段工作包
1. BE-00 后端基础框架与统一 REST 能力；
2. BE-01 Schema / Migration；
3. BE-02 Portal Session 与认证主体；
4. BE-03 portal_admin_user + RBAC；
5. BE-04 application + application_integration；
6. BE-05 申请/授权/账号映射；
7. BE-06 TODO / MESSAGE；
8. BE-07 公告；
9. BE-08 审计、运行监控与管理首页聚合；
10. BE-13 数据迁移演练、切换与回归准备。

### B阶段特别约束
- LOCAL 不得重新写入 unified_user；
- 新 API 不接受 scopes 作为权威权限；
- 前端冻结 DTO 不反向迁就 P3 旧字段；
- runtimeStatus 不允许由管理页面直接写 NORMAL；
- SMS 历史结构必须确认无运行依赖后才退役；
- P4RUN_STATE 只能作为过渡回归数据，不得继续成为正式业务真相源。
