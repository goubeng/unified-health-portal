## B阶段：0.3.0-B 数据库改造

### 启动前置
必须先完成A阶段验收并冻结前端DTO/状态/Service契约。

### 本阶段内容
- 新增Migration；
- Schema/Seed调整；
- PostgreSQL 14约束；
- NocoDB原生表结构同步；
- 本地数据库实际执行；
- 数据库读回与反例验证。

### 数据库访问安全标记
任何本地数据库操作必须记录：
1. 执行日期；
2. 执行者/执行环境；
3. 目标base/source/schema；
4. Migration文件及SHA；
5. 是否只读/写入；
6. 执行结果；
7. 回读结果；
8. 回滚/恢复方式。

未取得上述信息或未实际执行时，只能标记：
> **数据库改造：未执行 / 待本地环境验证**

不得因为Git中已有SQL就写“数据库已完成”。
