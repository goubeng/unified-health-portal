# 卫健XC统一门户系统 · 当前用户与角色体系说明

> 当前目标基线：V20260920-03  
> 当前代码版本：0.2.0（P4 Mock基线）  
> 下一阶段：0.3.0规划中

## 当前身份来源

```text
闽政通      → 公众用户
闽政务      → 政务用户
门户本地    → 门户本地用户
```

门户本地用户用于解决维护人员没有闽政通/闽政务账号时的管理端登录问题。

## 当前默认门户角色

仅预置：

1. 门户超级管理员（SUPER_ADMIN）
2. 门户管理员（PORTAL_ADMIN）

不再预置应用管理员、集成管理员、公告管理员、审计管理员、映射管理员等多个细分角色。

RBAC仍保留菜单、页面、操作权限，未来按需扩展自定义角色。

## 核心边界

- 用户类别不是角色；
- 本地用户不是自动管理员；
- 进入管理端必须有有效门户管理角色；
- 门户角色只管理门户自身权限；
- 子系统业务角色和业务权限仍由子系统负责；
- 应用访问申请通过只表示门户入口资格。
