# 项目教训

- 继承历史约束：真实入库必须通过数据库读回证明；浏览器 Mock 成功、localStorage 或接口占位不能称为数据库 CRUD 完成。
- 登录仍是原型模拟，不能因数据库改造擅自接入真实用户名、密码或认证流程。
- 外部系统尚未对位，本轮不得伪称联调完成；接口预留和前端演示须与真实接通明确区分。
- 演示状态验收不能只核对种子字段或记录数，必须用数据库当前用户身份读取真实页面动作；旧应用映射、授权范围、待办、消息和异常要一起核对。
- 用户授予管理角色后仍提示无权限时，应追踪当前会话主体、角色权限和管理端切换链路，不能只给数据库记录补角色即宣布修复。
- 日志页验收不能只看标题、条数或 SQL 不报错；要逐类对照前端列表及详情定义的字段，核查数据库物理列、审计事件 details 和 Repository DTO 是否真的有值，并区分历史样本缺失与当前新事件映射缺陷。
