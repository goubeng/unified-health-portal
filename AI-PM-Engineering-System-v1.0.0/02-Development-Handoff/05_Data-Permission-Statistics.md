# 数据模型、权限与统计口径

## 数据模型

需要明确：

- 表/对象
- 字段
- 类型
- 必填
- 默认值
- 唯一性
- 关联关系
- 字典
- 删除策略
- 审计字段
- 数据来源

## 权限矩阵

建议区分：

- 菜单访问
- 页面访问
- 操作显示
- 数据范围（仅项目需要时）

原型/演示项目可以只做前端显示控制，但文档要明确其并非生产级 API 鉴权。

## 统计口径

每个指标必须定义：

| 指标 | 业务定义 | 计算公式 | 数据源 | 时间范围 | 去重规则 | 状态范围 | 单位 |
|---|---|---|---|---|---|---|---|

避免“完成率”“总数”“有效在住”等指标在不同页面口径不一致。
