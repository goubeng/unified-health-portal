# 功能清单与页面规格规范

## 功能清单最小字段

| 字段 | 说明 |
|---|---|
| 模块 | 一级/二级模块 |
| 功能点 | 可验证的功能 |
| 功能说明 | 做什么 |
| 适用角色 | 谁使用 |
| 优先级 | P0/P1/P2 |
| 数据方式 | DB/Mock/Derived |
| 实现状态 | 过程阶段使用 |

## 页面规格

每个页面至少定义：

- 页面名称/路由
- 页面目的
- 查询条件
- 统计卡片
- Tabs
- 列表字段与顺序
- 默认排序
- 分页
- 详情字段
- 新增/编辑字段
- 操作按钮
- 弹窗/抽屉
- 状态 Tag
- 空态
- 权限
- 数据源
- 页面跳转
