# 演示环境部署 SOP

即使只是演示环境，也要可重复部署。

## 部署前记录

- OS
- Node 版本
- npm/pnpm 版本
- PostgreSQL 版本
- NocoDB 版本
- 端口
- 数据库名/用户
- 环境变量
- Token 获取方式
- 前后端启动方式

## 推荐流程

```text
环境检测
→ 数据库可连接
→ 数据库初始化/升级
→ NocoDB/API 配置
→ 安装依赖
→ 构建
→ 启动
→ 健康检查
→ 输出访问地址
```

## 不允许

- 只在开发者机器上能运行；
- 数据库修改没有脚本；
- Token/密码写死进源码；
- 部署说明与实际包不一致。
