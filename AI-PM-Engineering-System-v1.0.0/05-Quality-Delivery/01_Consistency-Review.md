# P7 · 交付前一致性复核

## 核心原则

最终文档生成前，必须重新读取当前系统，而不是相信历史文档。

## 复核矩阵

| 复核对象 | 对照对象 |
|---|---|
| 功能清单 | 当前菜单/路由/代码 |
| 页面规格 | 当前页面行为 |
| 状态机 | 当前状态字段与动作 |
| 操作矩阵 | 当前按钮/校验/Service |
| 数据模型 | 当前 DB Schema |
| 字典 | 当前字典数据/代码 |
| 权限 | 当前角色与页面控制 |
| 操作履历 | 当前写入逻辑与模板 |
| 消息 | 当前触发、接收人、跳转 |
| 统计口径 | 当前查询/计算逻辑 |
| 部署说明 | 当前实际环境与脚本 |

## 结果分类

- A：一致
- B：发现差异，已修正
- C：存在差异，明确保留并说明
- D：阻断交付

P7 通过前不能进入最终文档冻结。
