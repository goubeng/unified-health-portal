# 工程体系修订履历

遵循语义化版本思路：

- MAJOR：工程体系结构或项目执行方式发生不兼容变化。
- MINOR：新增 SOP、能力或阶段规则，原有使用方式仍兼容。
- PATCH：文字修正、模板优化、检查项补充，不改变核心流程。

## v1.0.0 - 2026-09-16

### Added

- 将单一新建项目 SOP 重构为五类项目路由。
- 增加快速演示原型、大屏驾驶舱、混合型项目 SOP。
- 增加已有系统迭代的最小修改与影响分析流程。
- 将 Mock 从“禁止使用”调整为“按数据类型选择，统一管理”。
- 将 Vue + TDesign 定为默认 UI 技术基线。
- 增加 Service Layer，隔离 Vue 页面与 NocoDB / Mock 数据源。
- 增加开发交接设计层：功能清单、页面规格、状态机、操作矩阵、字段规则、数据模型、权限矩阵、操作履历、消息通知、统计口径。
- 增加 P7 一致性复核、P7.5 基线冻结、P8 最终文档、P9 发布部署。
- 增加版本管理、变更影响追踪和最终交付包规范。

### Changed

- 公共表不再规定“每个项目全部必建”，改为按项目阶段与需要启用。
- 消息通知由前置完整设计改为“早期预留 + 业务稳定后补全”。
- 权限由一次性完整设计改为“基础角色前置 + 完整矩阵后补”。
- 脚手架由“每项目重新生成”改为“Base Project 优先复用”。

### Source

本版本基于原 `SOP-final` 的状态机、操作矩阵、消息清单、代码规范、交付核查和交付文档思想重构，并结合实际项目工作方式进行分流和工程化。
