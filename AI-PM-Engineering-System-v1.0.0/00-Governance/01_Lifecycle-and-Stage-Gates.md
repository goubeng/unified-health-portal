# 生命周期与 Stage Gates

## P0 · 项目识别与初始化

**输入：** 需求、建设清单、旧系统、源码、截图、现有数据库、母版工程。  
**动作：** 项目分类、技术基线确认、数据策略、公共能力策略。  
**输出：** PROJECT_PROFILE、project.yaml、SCOPE。  
**Gate：** AI 能仅依靠项目档案说明“做什么、怎么做、做到什么程度”。

## P1 · 需求与范围

**输入：** P0 + 需求材料。  
**动作：** 梳理角色、业务对象、功能边界、MVP、排除项、待确认项。  
**输出：** 功能清单初版、角色清单、业务对象清单、范围边界。  
**Gate：** 不存在影响整体方向的高风险歧义。

## P2 · 产品与业务设计

**输入：** P1。  
**动作：** 菜单、页面、核心流程、页面规格、核心状态机、字段规则。  
**输出：** PAGE_SPEC、FLOW、STATE_MACHINE 初版。  
**Gate：** 核心业务页面和核心状态可进入开发。

## P3 · 数据与开发交接设计

**输入：** P2。  
**动作：** 数据源分类、表结构、Mock 结构、Service 接口、核心操作矩阵。  
**输出：** DATA_DESIGN、核心操作矩阵、数据库 Schema/Seed、Mock Schema。  
**Gate：** 开发知道“数据从哪里来、页面做什么、状态如何变”。

## P4 · 快速 Coding

**输入：** P0~P3 + Base Project。  
**动作：** 复制/同步底座、实现核心页面和 CRUD。  
**输出：** 可运行版本。  
**Gate：** 核心页面无阻断错误，数据可正常读写或按 Mock 结构展示。

## P5 · 核心业务闭环

**输入：** 可运行版本。  
**动作：** 从头到尾真实操作核心业务，修正状态、字段、按钮、流程。  
**输出：** 稳定核心业务基线。  
**Gate：** 主要业务路径可完整跑通。

## P6 · 系统能力补全

**输入：** P5 稳定业务。  
**动作：** 补完整权限、字典、消息、操作履历、统计、导出、异常提示。  
**输出：** 完整操作矩阵、消息矩阵、履历规则、权限矩阵、统计口径。  
**Gate：** 系统完整性达到本项目交付级别。

## P7 · 一致性复核

**输入：** 当前代码、数据库、配置、页面行为、所有设计资产。  
**动作：** 交叉复核并修正差异。  
**输出：** 一致性复核报告。  
**Gate：** 无未解释的 P0/P1 差异。

## P7.5 · 基线冻结

将当前有效设计资产标记为当前版本基线：

- BASELINE.md
- 文档版本号
- 数据库 Schema 版本
- 当前 Git Commit（如有）
- 当前 Release Candidate

冻结后再生成最终交付文档。

## P8 · 最终文档生成

最终文档只能基于 P7 复核后的基线生成。

## P9 · 发布、打包与部署

输出：

- 全量源码包
- 补丁包（如适用）
- 数据库初始化 / 升级包
- 最终文档包
- 演示部署包
- Release Manifest
