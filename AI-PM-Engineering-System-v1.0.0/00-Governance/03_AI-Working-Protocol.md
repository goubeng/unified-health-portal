# AI 协作执行协议

## 1. AI 每次开始工作先读取

优先：

1. `.project/project.yaml`
2. `.project/PROJECT_PROFILE.md`
3. `.project/SCOPE.md`
4. `.project/DECISIONS.md`
5. `.project/CHANGELOG.md`
6. 当前阶段所需设计资产

禁止无视这些文件后重新从头假设。

## 2. AI 每次任务先判断

- 当前项目类型
- 当前阶段
- 是否属于新功能、迭代、修复、交付、部署
- 是否影响数据库
- 是否影响状态机
- 是否影响操作矩阵
- 是否影响消息/履历/权限/统计
- 是否需要版本升级

## 3. 输出格式

每次较大变更完成时输出：

```text
【本次完成】
【修改文件】
【影响资产】
【数据库变更】
【验证结果】
【文档同步】
【建议版本】
```

## 4. 不允许 AI 自行创造最终事实

不明确的信息：

- 开发前：标记【待确认】；
- 开发后复核：通过代码/数据库/页面验证；
- 仍无法确定：进入一致性复核报告的“保留差异”。

## 5. 最终文档禁止直接从旧文档改写

必须重新检查当前系统，再生成当前版本最终文档。
