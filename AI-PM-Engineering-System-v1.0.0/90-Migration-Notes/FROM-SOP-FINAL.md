# 从原 SOP-final 到当前工程体系的主要变化

原 SOP 中值得保留的资产：

- 调研准备
- 角色与权限
- 业务对象
- 状态机
- 功能清单
- 业务操作矩阵
- 消息触发清单
- 代码规范
- 交付前核查
- 最终交付文档

本次重构的核心变化：

1. 从“单一新项目线性 SOP”变成“项目类型 Router + 多 SOP”。
2. 从 Acro Design 默认技术基线调整为 Vue + TDesign。
3. 从“全程真实数据库、禁止 Mock”改为 DB / Mock / Derived 分类。
4. 从“所有公共表每项目必建”改为公共能力按需启用。
5. 从“开发前尽量一次设计完整”改为：
   - Coding 前确定核心规则；
   - 核心业务跑通后再补完整权限、消息、履历等。
6. 新增 Service Layer，页面不直接依赖数据源实现。
7. 新增 P7 一致性复核和 P7.5 基线冻结。
8. 最终交付文档必须从当前系统反向复核生成。
9. 新增版本、Release Manifest、数据库 Migration、演示部署规范。
