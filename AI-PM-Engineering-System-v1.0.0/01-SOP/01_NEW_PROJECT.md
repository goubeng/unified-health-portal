# SOP-A · 新建业务管理系统

适用于从 0 到 1 建设真实 CRUD 为核心的业务系统。

## 流程

1. P0：复制 Base Project，建立项目档案。
2. P1：明确角色、对象、范围、核心功能。
3. P2：菜单、页面规格、核心流程、状态机。
4. P3：设计业务表、字典、Service 契约。
5. P4：优先完成核心 CRUD。
6. P5：跑通核心业务闭环并迭代。
7. P6：补权限、消息、操作履历、统计、导出等。
8. P7：全系统一致性复核。
9. P7.5：冻结基线。
10. P8：生成最终开发交接与使用文档。
11. P9：全量包、数据库包、部署包。

## 公共模块策略

- 字典：建议早期启用。
- 用户/组织：业务字段真实引用时启用。
- 角色：先基础角色；完整操作权限在 P6 收敛。
- 消息：数据表和页面可预留；触发规则 P6 完整化。
- audit_log：按验收/审计需要启用。
