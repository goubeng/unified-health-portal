# SOP-C · 快速演示原型

目标：短时间做出“可运行、可操作、有动态数据、可汇报”的系统，而不是生产级后端。

## 数据策略

推荐混合：

- 用户/组织/核心业务列表：真实 CRUD
- 趋势/统计/设备/地图：Mock
- 消息：可先演示数据，业务稳定后再接真实触发
- 权限：演示级前端控制

## 建设顺序

```text
演示目标
→ 核心场景
→ 页面结构
→ 核心 CRUD
→ Mock 数据
→ 场景串联
→ UI统一
→ 一致性复核
→ 演示部署
```

## 完成标准

不是“后端全部真实”，而是：

- 关键数据不是页面硬编码；
- 关键操作可演示；
- 刷新后应持久化的数据真实保存；
- 演示路径不出现断点；
- 最终文档明确真实数据与 Mock 数据边界。
