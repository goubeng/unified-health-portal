# UI 与 Base Project 规范

## Base Project 应沉淀

- 主框架 Layout
- 菜单/路由
- 登录/用户切换（按项目）
- 公共查询区
- 标准列表
- 标准详情
- 标准表单
- Dialog / Drawer
- Tag
- Empty
- Pagination
- 公共样式
- Design Tokens
- System Modules

## 统一原则

- 优先 TDesign 默认能力；
- 项目级新增样式尽量进入统一样式文件；
- 弹窗、查询区、表格、标题、Tab、空态等保持一致；
- 不允许各页面反复重新定义相同视觉规则。

Base Project 本身也需要独立版本，例如：

`Base-Project v1.3.0`
