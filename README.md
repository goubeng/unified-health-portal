# 卫健XC统一门户 · P4交互原型

当前0.2.0，Vue3 + Vite + TDesign。P3阶段验收通过，P4持续开发；不是生产发布包。

## 本地运行

Node.js 20.19+或22 LTS，首次执行 `npm ci`。保持两个终端运行：

1. `npm run api`：本地服务3801，需访问现有Docker postgres14/nocodb_data。
2. `npm run dev`：浏览器入口 http://127.0.0.1:3800 ，固定端口，不自动换端口。

登录选择公众/政务后直接点击登录，不验证手机号、验证码或滑块；扫码页也可直接登录。头部可切换账号。身份切换仅用于原型，不代表真实认证。

构建 `npm run build`；测试 `npm test`；P3静态校验 `npm run check:p3`。

## 数据与接入边界

- 42个应用来自原始需求未划除清单。当前公众15个、政务41个启用应用，管理目录42个（含1停用）。适用范围是可维护的原型配置，业务方尚未逐项确认授权矩阵。
- 本地API将原型状态保存至指定schema `pb3gir75kkooyea` 的system_config中P4RUN_STATE，业务变化部分镜像至原生表；审计写入audit_event。不是原NocoDB正式数据的通用生产适配器。
- 初始P4FIX_样本23表457行已写入读回；原12项配置保留。运行时新增规则/快照/审计后总量会变化。
- 用户、应用、公告、待办、消息、规则、接入配置有原生表写入。自定义角色/映射等以持久化原型快照为准，完整规范化同步仍待后续实现。
- 草稿可删除；过期公告规则默认0（关闭），开启后每分钟检查，删除仅移出活跃列表/表，完整记录保留回收档案。当前无回收页面。
- 接入配置与接口文件下载用于原型交互，不依赖任何真实子系统。提供本地PUSH契约供后续对照；真实外部认证、SSO、账号核验、公开接入地址均未接通。
- 不需要登录密码或验证码。外部接口可选凭据仅为后续本地PUSH测试预留，配置只保存环境变量名，前端不保存密钥。
- 页面没有跨项目样式或目录链接；空态使用本地src/assets/nopic.svg。
- 仅监听本机；不得直接发布为生产系统。保留业务角色范围和数据归属规则，不将“免登录校验”等同于取消应用展示过滤。
