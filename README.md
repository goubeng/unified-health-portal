## 本地运行

Node.js 20.19+或22 LTS，首次执行 `npm ci`。保持两个终端运行：

1. `npm run api`：本地服务3801，访问现有Docker PostgreSQL/NocoDB数据源；
2. `npm run dev`：浏览器入口 http://127.0.0.1:3800。

构建：`npm run build`；测试：`npm test`；P3静态校验：`npm run check:p3`。

## 当前实现边界

当前登录、SSO、子系统账号核验、PUSH外部联调仍以Mock/本地契约为主，不代表正式生产集成。

最新目标身份模型为：

- 闽政通 → CITIZEN / 公众用户；
- 闽政务 → GOV / 政务用户；
- 门户本地 → LOCAL / 门户本地用户。

默认门户角色收敛为 SUPER_ADMIN 和 PORTAL_ADMIN，子系统业务角色和业务权限仍由各子系统负责。
